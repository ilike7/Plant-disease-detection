
# Plant Disease Detection Using Deep Learning

## Project Overview
This project aims to detect plant diseases from leaf images using deep learning and image classification techniques. The system will accept a leaf image and predict the corresponding plant disease class.

## Objectives
- Identify plant diseases from leaf images.
- Prepare and preprocess an image dataset.
- Train and compare deep learning models.
- Evaluate models using accuracy, precision, recall, and F1-score.
- Develop a user-friendly interface using Streamlit.

## Technologies
- Python
- Google Colab
- TensorFlow / Keras
- NumPy and Pandas
- Matplotlib and Seaborn
- Scikit-learn
- Streamlit
- GitHub

## Dataset
The project plans to use the PlantVillage dataset. Dataset preparation and class selection will be documented during development.

## Planned Workflow
1. Collect and inspect the dataset.
2. Preprocess images and split the dataset.
3. Train and compare deep learning models.
4. Evaluate model performance.
5. Integrate the selected model into a Streamlit application.
6. Test and document the final system.
